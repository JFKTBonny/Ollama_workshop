*** The generate-style API accepts a single prompt and returns a single response...
    The chat-style API accepts a list of messages, each with a role, so the model can respond in the context of a conversation...

    In practice, every chatbot works by sending the conversation history back to the model on each turn...
    The model does not magically remember prior messages unless you include them in the  request...

    *** The chat endpoint expects a messages array...
        Each item in that array is a dictionary containing a role and some content...
        A role can be:
           1- system: instructions that define how the assistant should behave...
           2- user: a message from the user...
           3- assistant: a previous response from the model...
